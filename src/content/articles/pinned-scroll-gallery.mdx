The Work section on this site pins one column while the other scrolls past. The effect looks complicated, but the core of it is plain CSS.

## The layout

Two columns sit inside one tall container. The left column is sticky and fills the viewport, while the right column flows normally and sets the height of the whole section.

```tsx title="pinned-gallery.tsx"
export function PinnedGallery({ items }: { items: string[] }) {
  return (
    <section className="grid grid-cols-2 gap-10">
      <div className="sticky top-0 h-screen">
        <div className="flex h-full items-center">Pinned column</div>
      </div>
      <div className="flex flex-col gap-24 py-24">
        {items.map((item) => (
          <div key={item} className="aspect-[4/5]">
            {item}
          </div>
        ))}
      </div>
    </section>
  )
}
```

## Adding the motion

Position alone gives the pinned effect. Motion adds a gentle parallax to the images and fades the active caption in and out as each item crosses the middle of the screen.

## Phones

Two columns do not fit on a small screen, so below the tablet breakpoint the section becomes a simple vertical list. Sticky layouts on touch devices also fight with browser toolbars, so removing them there is the safer choice.

Always test with reduced motion switched on. The layout should still make sense with every animation turned off.
